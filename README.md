# CP嗒啧 (Orclavitasyn)

## 关于

CP嗒啧（英文名：Orclavitasyn）是一个专注于金缮（Kintsugi）艺术的伴侣应用。我们相信，每一件器物都承载着记忆与温度，而修复不仅是技艺，更是一种对待生活的态度。

在这里，人们记录修复的旅程，发现不完美中的独特之美，获得AI辅助的技法指导。

## 我们的故事

金缮是一门拥有400年历史的日本传统技艺，以金线修补破碎的陶器，让裂痕成为器物生命的一部分。这种哲学启发了我们：破损不是终点，而是另一种开始。

Orclavitasyn 这个名字融合了金（Or来自拉丁语aurum）、陶土（Cla）、生命（Vita）、修复（Men）与连接（Syn）的意象，象征着将碎片重新编织成完整的过程。

## 核心功能

- **修复项目记录**：拍摄破损器物照片，记录损坏类型、材质、美学偏好
- **裂痕叙事生成**：AI为每个修复项目生成富有诗意的裂痕故事
- **AI技法助手**：回答金缮技法、材料推荐、哲学讨论等问题
- **项目画廊**：展示和管理所有修复项目的进度
