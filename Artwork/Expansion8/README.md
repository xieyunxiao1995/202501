# Expansion8 artwork

Eight independent portrait renders and eight independent environment renders generated with the built-in imagegen tool. All characters are original fictional adults, age 30–45, in modest professional clothing. Source files and role/environment art briefs are preserved here. The portrait also supplies its matching avatar thumbnail; only fitting/cropping for asset dimensions is performed by Tools/prepare_expansion8_assets.py. Preview.jpg uses the actual asset-catalog files.
