# Tideverse marketing assets

Tideverse is an existing native iPhone story and fictional AI character app. Project evidence: 40 original adult characters, 328 authored chapters, four tabs (Discover, Chats, Journeys, Settings), story choices and saved moments. The UI and supplied screenshots are English, midnight blue. User requested only iPhone assets and explicitly selected character appeal and story atmosphere as the redesign priority. This package changes marketing artwork only; the app and its installation icon are outside this revision.
